# Security guide

## Multi-factor authentication
Multi-factor authentication is mandatory for all company accounts. Use a hardware security key or an authenticator app for multi-factor authentication. SMS authentication is not permitted.

## Lost laptop
Report a lost laptop immediately to security@example.test and the IT help desk. The security team will revoke active sessions and initiate a remote wipe of the lost laptop.

## Password manager
Store work passwords in the company-approved password manager, VaultBox. Never share passwords through chat or email.

## Customer data
Customer data must only be stored in approved company systems. Never copy customer data to personal devices or public AI tools.

## Phishing reports
Report suspected phishing using the Report Phishing button in your mail client. Do not click links or open attachments in suspected phishing messages.

## VPN access
VPN access is required when connecting to internal production services. Request VPN access through the IT help desk with manager approval.
